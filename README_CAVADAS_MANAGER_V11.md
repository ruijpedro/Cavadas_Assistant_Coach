# Cavadas Manager V11

Versão tablet-first do 1. FC Gruefwiss Leideleng, sem IA.

Inclui:
- PT / DE / FR / LB
- Plantel inicial com 6 atletas
- Fichas individuais (nascimento, altura, peso atual/ideal, posição, PD, PO, capitão, notas)
- Avaliações de velocidade 5m/10m/20m/30m e velocidade máxima
- Convocatórias + PDF
- Treinos e biblioteca de exercícios
- Quadro tático: Futsal, Futebol 11, 7 e 6
- Adicionar/remover jogadores, passe, movimento, remate e fases
- Identidade visual do clube
- Ícone Android do pacote ic_launcher (6)
- GitHub Actions para WebApp e APK
