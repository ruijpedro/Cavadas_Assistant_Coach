# CAVADAS MANAGER V22.1.1 — MOBILE

Versão otimizada para telemóvel da V22.1.0, preservando os dados, módulos e lógica existentes.

## Alterações principais
- Navegação inferior horizontal pensada para uso com o polegar.
- Cabeçalho compacto com o espaçamento entre `ÉPOCA 26/27` e `Autor RJP` preservado.
- Formulários e botões com alvos tácteis adequados ao telemóvel.
- Estatística de jogo/desempenho em disposição vertical e sempre editável/preenchível.
- Quadro tático adaptado a ecrã vertical, mantendo edição por toque.
- Planeamento semanal em cartões deslizáveis.
- Tabelas completas com scroll horizontal, sem esconder colunas.
- Ajuda, biblioteca e importação em coluna única.
- Safe areas para Android/PWA e ecrãs com recortes.

## Base
Mantém a funcionalidade da V22.1.0. A alteração é sobretudo de interface/responsividade para smartphone.
