# Cavadas Tactical V5.2 — Esquemas de Treino Futebol/Futsal

Nova funcionalidade:
- Em Futebol e Futsal existe agora o painel “Esquema de treino”.
- O treinador escolhe:
  - Jogadores de campo
  - Guarda-redes
- Para jogadores de campo:
  - número de atacantes
  - número de defensores
  - incluir ou não guarda-redes
- Para guarda-redes:
  - a app gera automaticamente um exercício com GR, rematadores, apoios e oposição.
- Aplica automaticamente os jogadores no campo.

Objetivo:
Permitir criar esquemas de treino para:
- futebol
- futsal
- jogadores de campo
- guarda-redes
- cantos
- livres
- bolas paradas
- transições
- finalização
