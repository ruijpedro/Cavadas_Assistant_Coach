# Cavadas Manager V22.5 — Voice Coach

Melhorias do interface e motor de voz:
- aceita comandos abreviados por número: `2 diagonal, 3 segundo poste`;
- interpreta automaticamente logo após a transcrição, mas nunca aplica sem confirmação;
- percentagem de confiança da interpretação;
- chips de léxico tático;
- últimos 5 comandos reutilizáveis;
- exemplos e correção por texto;
- mantém voz nativa Android + fallback Web;
- mantém 2.º poste, bola aérea, afundar, fundo, bola no meio e finalização.

Fluxo: `Dizer jogada → interpretação automática → rever → Criar animação → PLAY`.
