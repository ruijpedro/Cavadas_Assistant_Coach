# Cavadas Manager V15.0 — Tactical Animation

Grande evolução do Quadro Tático inspirada no fluxo de ferramentas modernas de futsal, sem copiar interfaces proprietárias.

## Novidades
- Cada fase/fotograma guarda:
  - posições dos jogadores;
  - posição da bola;
  - objetos;
  - zonas;
  - textos;
  - desenhos/setas.
- Nova fase e duplicar fase.
- Duração individual de cada fase.
- Velocidade de reprodução: 0,5× / 1× / 1,5× / 2×.
- Reprodução animada entre fases.
- Interpolação suave das posições dos jogadores e da bola.
- Guardar fase manualmente.
- Guardar exercício com sequência completa de fases.
- Mantém ferramentas V14: movimento, passe, remate, curvas, cones, marcadores, barreiras, escadas, mini-balizas, zonas e texto.
- Mantém V14.6 e Android icon fix.
- Sem IA.
