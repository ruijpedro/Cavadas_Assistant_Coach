# Cavadas Manager V22.4 — Léxico Tático de Futsal

Inclui um dicionário interno de conceitos táticos ligado ao reconhecimento de voz. A base terminológica foi estruturada a partir do Glossário FIFA e de manuais/terminologia de treino UEFA/CONMEBOL, complementada com variantes de linguagem corrente PT-PT, PT-BR e ES para melhorar reconhecimento.

O menu **Léxico Futsal** permite procurar por termo, categoria, definição e sinónimos de voz.

O motor reconhece o léxico como camada semântica; as ações geométricas já implementadas continuam a ser executadas diretamente e os conceitos mais complexos ficam preparados para expansão progressiva do parser.
