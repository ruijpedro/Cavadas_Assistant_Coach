# Cavadas Manager V20.0 — Versão de Utilização

Consolidação da V19 Interpreter V2 para utilização prática.

## Incluído
- Importação local/offline: PDF, PPTX, imagem/manuscrito e vídeo.
- Diagnóstico tático após interpretação.
- 3 propostas de solução para revisão do treinador, sem aplicação automática.
- Princípios-base: espaço, linhas de passe, equilíbrio, cobertura, superioridade e reação à perda.
- Treino: filtro dedicado `🧤 Específico GR · 10`.
- 10 exercícios específicos de GR com objetivo, organização, duração, correções e progressão/notas.
- Biblioteca, quadro tático, PLAY fullscreen, variantes, sessões, convocatórias e restante base V19 preservados.

## Nota técnica
- Preflight passou.
- `src/importEngineV2.js` passou `node --check`.
- O build Vite completo não ficou validado neste ambiente porque a instalação de dependências excedeu o tempo disponível; GitHub Actions permanece como via de compilação APK.
- As propostas táticas são apoio à decisão do treinador e não são apresentadas como uma única solução universal.
