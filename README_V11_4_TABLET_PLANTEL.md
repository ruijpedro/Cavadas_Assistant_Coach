# Cavadas Manager Gruefwiss V11.4 — Tablet / Plantel Editável

## Novidades
- Adicionar atletas diretamente no Plantel.
- Editar todos os dados do atleta.
- Eliminar qualquer atleta, incluindo os atletas inicialmente pré-carregados.
- Confirmação antes de eliminar.
- Depois de eliminado, o atleta não volta a ser criado automaticamente.
- Seleção automática do atleta seguinte após uma eliminação.
- Estado vazio com botão para criar o primeiro atleta.
- Botões maiores e organização específica para tablet.
- Funciona em landscape e portrait.
- Dados persistidos localmente no dispositivo.
