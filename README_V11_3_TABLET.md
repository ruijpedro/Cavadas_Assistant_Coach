# Cavadas Manager Gruefwiss V11.3 — Tablet

Versão tablet-first para Android/iPad.

- botões e campos tácteis com pelo menos 48 px;
- navegação adaptada a ecrãs de tablet;
- modo horizontal privilegiado para o Quadro Tático;
- modo vertical com reorganização automática;
- quadro táctico com maior área útil;
- painel de ferramentas fixo em landscape;
- listas, fichas de atletas e convocatórias adaptadas ao toque;
- suporte PT / DE / FR / LB / EN;
- mantém os 7 atletas iniciais;
- preparado para GitHub Actions / Android APK.
