# Cavadas Manager V18.0 — Importador Tático

Novo módulo **Importar Tática** com processamento local/offline:

- **PDF**: lê texto/páginas, identifica títulos táticos e cria candidatos editáveis por página/bloco.
- **PPTX**: lê slides e formas, agrupa blocos de canto, saída de pressão, livres/foras, 3:1, 4:0, 2:2, linhas defensivas e trocas; cria passos para o motor de animação.
- **Vídeo**: amostra temporalmente o vídeo e tenta seguir marcadores coloridos/peças de quadros táticos para gerar uma sequência de frames animáveis.
- Pré-visualização, confiança, número de passos/peças.
- **Guardar na Biblioteca** ou **Abrir animação** diretamente no Quadro Tático.
- PT / DE / FR / LB / EN para o novo módulo.

## Limites intencionais
A importação é semi-automática. PDF estático e vídeo real podem não conter informação suficiente para reconstruir movimentos exatos; a app assinala confiança e permite rever no Quadro Tático. O modo vídeo V18 é especialmente orientado a vídeos de quadros táticos com campo fixo e marcadores visuais.
