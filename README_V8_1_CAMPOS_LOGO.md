# Cavadas Tactical V8.1 — Campos + Logo/Ícones

Alterações aplicadas:
- Campo principal substituído por SVG profissional, sem divs antigas.
- Campo de futebol com relva listada, grande área, pequena área, penálti, meia-lua, cantos e balizas com rede.
- Campo de futsal com área semicircular, marcas de 6 m e 10 m, cantos, zonas de substituição e balizas pequenas.
- AnimationPlayer V7 também usa os novos campos SVG.
- Integração do icon enviado: `android-assets/res`, `public/icon.png`, manifest web e script `npm run apply-icons`.
- Workflow Android aplica os ícones após `npx cap sync android`.

Nota: se o ícone Android continuar genérico, desinstala a app antiga do telemóvel e instala o novo APK.
