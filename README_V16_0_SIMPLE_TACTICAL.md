# Cavadas Manager V16.0 — Simple Tactical

Quadro tático redesenhado para ser simples e intuitivo.

Fluxo:
1. Posicionar jogadores e bola.
2. Tocar em + Passo.
3. Mover jogadores/bola.
4. PLAY.

Inclui:
- campo gráfico permanente;
- peças circulares numeradas;
- nossa equipa e adversário diferenciados;
- bola;
- movimento e passe;
- setas;
- passos da jogada;
- animação automática suave;
- guardar jogada;
- mantém restantes módulos e Android icon fix;
- sem IA.
