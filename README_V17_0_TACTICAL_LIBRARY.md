# Cavadas Manager V17.0 — Biblioteca Tática

Biblioteca base integrada na mecânica do quadro tático.

Inclui:
- 3x1 e 3x2;
- progressões 1+GRx2, 2+GRx3 e 4+GRx5;
- modelos defensivos: linhas/coberturas e trocas;
- modelos ofensivos 3:1 e 4:0;
- 2 bolas de saída;
- 5 cantos;
- 5 saídas de pressão;
- 2 foras/livres laterais.

Fluxo:
Biblioteca → Abrir animação → PLAY → editar → Guardar variante → adicionar ao treino.

As jogadas da biblioteca usam o motor de Passos da Jogada e podem ser editadas.
A sessão de treino já permite selecionar exercícios/jogadas da Biblioteca.
Sem IA.
