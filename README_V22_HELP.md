# Cavadas Manager V22.0 — Ajuda Integrada

Base: V20.0.4.

## Novidades
- Ajuda completa dentro da aplicação.
- Botão **Ajuda** no menu principal.
- Pesquisa por tarefas e termos.
- Atalhos “Quero fazer…” para convocatória, treino, animação, importação, bolas paradas e planeamento.
- Guia por módulos: atletas, treinos, exercícios, quadro tático, importador, bolas paradas, modelo de jogo, jogos, convocatórias, planeamento, documentos/partilha e pós-jogo.
- Avisos claros sobre validação das importações e decisões do treinador.
- Cabeçalho da app mantém **CAVADAS MANAGER / ÉPOCA 26/27 / Autor RJP**, com espaçamento visual entre época e autor.
- Documentos mantêm apenas **RJP** discreto no final, conforme definido.
