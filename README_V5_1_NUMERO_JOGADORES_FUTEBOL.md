# Cavadas Tactical V5.1 — Número de jogadores no Futebol

Nova funcionalidade:
- Na modalidade Futebol aparece o painel “Jogadores na animação”.
- Permite escolher:
  - número de atacantes
  - número de defensores
  - incluir ou não guarda-redes
- Ao clicar “Aplicar jogadores no campo”, a app gera automaticamente as posições base.

Isto é útil para:
- cantos
- livres
- bolas paradas
- transições
- organização ofensiva
- exercícios com diferentes formatos: 3x2, 5x4, 7x6, 8x7, 11x11.
