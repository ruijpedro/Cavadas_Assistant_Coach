# Cavadas Manager V22.1.0 — Estatística de Jogo e Desempenho

- Novo editor de estatística de jogo e desempenho.
- Jogos guardados podem ser reabertos e editados.
- Eventos do jogo totalmente editáveis: minuto, parte, ação, atleta, zona e nota.
- Ações personalizadas criadas pelo treinador.
- Estatística coletiva preenchível manualmente.
- Desempenho individual editável por atleta: nota global, técnica, tática, físico, atitude e observações.
- Mantém os dados em armazenamento local.
- Preserva Ajuda V22, cabeçalho e restante base funcional.
