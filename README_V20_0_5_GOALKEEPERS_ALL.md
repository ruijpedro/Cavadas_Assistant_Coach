# Cavadas Manager V20.0.5 — GR em todos os exercícios

Correção transversal sobre a V20.0.4.

- Opção **Sem GR / GR nosso / GR adversário / Ambos os GR** no quadro tático.
- Aplicável a exercícios, cantos, foras/laterais, livres, bolas de saída, saídas de pressão, transições, jogadas estudadas e itens importados depois de abertos no quadro.
- GR nosso e adversário são peças distintas, móveis e animáveis em todos os passos.
- Novas bolas paradas começam com ambos os GR disponíveis.
- Exercícios da biblioteca passam a guardar a preferência de GR.
