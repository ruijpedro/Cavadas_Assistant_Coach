# Cavadas Manager V13.0 — Coaching Hub

Sem IA.

## Novos módulos
- Modelo de Jogo: identidade, organização ofensiva/defensiva, pressão, transições e princípios.
- Bolas Paradas: cantos, laterais, livres, 5x4 e defesa 4x5, integrados diretamente no Quadro Tático.
- Adversários: scouting pré-jogo, sistema, pontos fortes, fragilidades e bolas paradas.
- Análise Pós-jogo: reflexão ligada ao jogo, avaliação global, organização ofensiva/defensiva e prioridades para o treino seguinte.
