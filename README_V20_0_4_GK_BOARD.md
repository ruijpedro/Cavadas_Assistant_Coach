# Cavadas Manager V20.0.4 — GR no Quadro Tático

Atualização da V20.0.3 orientada ao uso real.

## Alterações
- Botão **GR nossa equipa** no Quadro Tático.
- Botão **GR adversário** no Quadro Tático.
- Representação visual distinta dos dois guarda-redes, mantendo a identidade de cada equipa.
- Os GR podem ser arrastados, participar nos passos/animações e ser guardados nas jogadas/exercícios.
- É possível adicionar mais de um GR de cada equipa para exercícios específicos.
- Mantém cabeçalho tablet: CAVADAS MANAGER / ÉPOCA 26/27 / Autor RJP.

## Compatibilidade
Jogadas antigas continuam a abrir normalmente; o campo `role: goalkeeper` só é acrescentado aos novos GR criados no quadro.
